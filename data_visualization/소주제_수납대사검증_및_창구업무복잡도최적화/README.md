# 수납·재정 대사 검증 및 창구 업무 복잡도 최적화 — 시각화 코드 (`data_visualization`)

본 디렉터리는 **소주제: 수납·재정 대사 정합성 검증 및 창구 업무 복잡도 최적화**의 시각화 차트 생성 코드, Streamlit 통합 대사 대시보드(`app.py`), 통일 디자인 발표자료 생성 코드 및 핵심 시각화 차트 5종을 포함합니다.

## 파일 구성
- `visualize_collection_charts.py`: 수납 패턴별 거래 비중, 피크 시간대(08~14시) 복수 거래 집중도, 정제 규칙별 격리 현황 차트 생성 스크립트
- `render_scenario_charts.py`: 수납 복잡화 시나리오(`BASE` vs `COLLECTION_COMPLEX`) 작업량 스택 차트 및 대사 근거 분류 차트 생성 스크립트
- `app.py`: 진료 단위 통합 대사 및 조건부 재확인 시뮬레이션 인터랙티브 대시보드 (Streamlit)
- `build_presentation_pptx.py`: Team 3 통일 디자인 시스템 기반 12장 보고서(`.pptx`) 자동 빌드 스크립트
- `차트_1_수납패턴별_진료비중_및_복수거래_분석.png`: 단일결제(1.0건) vs 분할결제(2.0건)·환불(2.03건) 복수 거래 구조 분석
- `차트_2_피크시간대_08_14시_복수거래_집중현황.png`: 08시 분할결제 피크(60.45%), 09~13시 외래 물량 집중(83.5%) 시간대 분석
- `차트_3_수납복잡화_시나리오_작업시간_절감효과.png`: 기본 2단계(20,937분) vs 3단계 전수 재확인(46,920분, +124.1%) 작업시간 비교
- `차트_4_정제규칙별_격리현황.png`: 원천 결함 및 부모키 연쇄 격리 현황
- `차트_5_대사근거_차이보류_분류.png`: 과거 로컬 기준 대사 근거 점검 시 일치(96.4%)·차이(1.09%)·보류(2.52%) 분리
