# 현장접수 분석 코드

이 폴더의 SQL은 DB 조회용이며, Python 분석 코드는 이미 추출한 CSV 01~03만 읽습니다. Python 실행 시 DB에 접속하거나 원본을 변경하지 않습니다.

- `01~04_*.sql`: 기존 조회 SQL. 이번 정리에서 수정하지 않음.
- `01~04_*.csv`: 기존 추출 결과. 이번 정리에서 이동·수정하지 않음.
- `analyze_walk_in.py`: 월별 대사, 진료과·시간대 집계, 반복 후보·민감도 계산.
- `analysis_results.json`: 분석 코드를 실행하면 생성되는 결과. 시각화 코드의 입력.
- `사용안내.txt`: 기존 SQL 실행 안내. 유지.

프로젝트 루트에서 실행합니다. Python 3.10 이상, `polars`가 필요합니다.

```powershell
python "data_analysis/진료과·시간대별 현장접수 불가 패턴 분석을 통한 사전 방문 안내 개선/analyze_walk_in.py"
```

입력·출력 위치를 바꾸려면 `--input-dir`, `--output`을 사용합니다. 기존 결과는 자동 덮어쓰지 않으므로 재실행할 때 다른 출력 파일을 지정하세요.

시각화·보고서 생성 코드는 같은 주제명의 `data_visualization` 폴더를 참고하세요. 이번 정리는 코드 배치만 대상으로 하며 기존 보고서·CSV 배치는 유지했습니다.
